# \[UPR\] Úvod do programování

This repository contains explanations and demonstrations of topics discussed during the UPR course
at VŠB-TUO. It is not currently part of the official study materials, but you can of course use
the contents of this repository to learn more about programming and the C programming language.

I try my best, but I make no guarantees. If you find any mistakes, feel free to create an issue
or submit a PR. It takes a long time to prepare the materials and mistakes can easily accumulate.

You can find the [official website for the UPR course here](https://github.com/geordi/upr-course).

### Disclaimer: You are not allowed to use materials from this repository during real-time tests

## `compile_flags.txt`

This file instructs your LSP which compiler flags to use when you open the file with your text
editor. If you open the `.c` files from the project directory, your LSP should load the file
automatically and show you better warnings, etc.

You can pretty much ignore the file. Things should work magically


## Online Classes

Online classes are **not** a replacement, but only a supplement for regular in-person classes.

Here, you can find information about potential planned/ongoing online classes, as well as
recordings of previous such classes. Online classes are not mandatory for anyone, including myself,
and will be organised only if my schedule allows it. The online sessions are similar to in-person
classes in both the topics covered and the examples I show, but the explanations can go more
in depth, because the online classes are unrestricted time-wise, and can span beyond the usual
90 minutes of time allocated for official classes.

The recordings were created by students with my explicit permission. I only put up what
the students send me, but I don't record the sessions myself, as organizing them already takes
plenty of effort. Thus, some online classes may have not been recorded.

Attending the online classes or watching the recordings is not mandatory, but may be very useful
for everyone, including the most knowledgeable students, as they often contain extra tidbits
of information and useful details which we don't have the time for during official classes.
